# Cartesi documentation examples

Complete projects for the tutorials of the [Cartesi Rollups documentation](https://docs.cartesi.io/cartesi-rollups/2.0/). Each project is what you get by following its tutorial step by step.

The projects target **Cartesi Rollups 2.0**:

- Cartesi CLI 2.0.0-alpha.42
- rollups-node v2.0.0-alpha.14
- rollups-contracts v3.0.0-alpha.10

| Project | Language | Tutorial |
| --- | --- | --- |
| [`ether-wallet`](ether-wallet) | TypeScript | [Integrating Ether wallet functionality](https://docs.cartesi.io/cartesi-rollups/2.0/tutorials/ether-wallet/) |
| [`erc-20-token-wallet`](erc-20-token-wallet) | TypeScript | [Integrating ERC20 token wallet functionality](https://docs.cartesi.io/cartesi-rollups/2.0/tutorials/erc-20-token-wallet/) |
| [`erc-721-token-wallet`](erc-721-token-wallet) | TypeScript | [Integrating ERC721 token wallet functionality](https://docs.cartesi.io/cartesi-rollups/2.0/tutorials/erc-721-token-wallet/) |
| [`erc-1155-token-wallet`](erc-1155-token-wallet) | TypeScript | [Integrating ERC1155 token wallet functionality](https://docs.cartesi.io/cartesi-rollups/2.0/tutorials/erc-1155-token-wallet/) |
| [`calculator`](calculator) | JavaScript, Python, Rust, Go, C++ | [Build a Calculator Application](https://docs.cartesi.io/cartesi-rollups/2.0/tutorials/calculator/) |

Every project needs the Cartesi CLI 2.0.0-alpha.42, Docker and Node.js 24+, and runs with `cartesi build` and `cartesi run` from its folder (see each project's README).

## Account abstraction examples

[`account-abstraction-frontend-demo`](account-abstraction-frontend-demo) and [`account-abstraction-script`](account-abstraction-script) were written for an earlier release of the Cartesi CLI and **do not work with the current release** listed above. They are kept for reference only.
